# 🧮 Calculadora

Uma calculadora desenvolvida em **C# utilizando o Visual Studio 2022**, inspirada no funcionamento das calculadoras simples e tradicionais.

O projeto foi desenvolvido como um exercício de **lógica de programação, operações matemáticas, manipulação de entradas do usuário e criação de uma interface funcional**.

A proposta é manter a experiência simples e direta: a calculadora realiza **um cálculo por vez**, assim como as calculadoras básicas do dia a dia.

Este projeto faz parte dos meus primeiros experimentos com C# e foi desenvolvido principalmente com o objetivo de **praticar, testar conceitos e transformar lógica de programação em algo funcional**.

## 🎯 Objetivos do projeto

* Praticar C# e lógica de programação;
* Trabalhar com operações matemáticas;
* Manipular entradas fornecidas pelo usuário;
* Implementar operações e resultados de forma sequencial;
* Desenvolver uma aplicação simples partindo do zero;
* Colocar em prática conceitos aprendidos durante os estudos.

## 🔢 Sobre a calculadora

A calculadora segue o conceito das calculadoras mais simples: o usuário informa os valores, escolhe uma operação e obtém o resultado antes de iniciar um novo cálculo.

A simplicidade é justamente parte da proposta do projeto, servindo como um exercício para compreender os fundamentos da programação e da construção de aplicações em C#.

> **Antes de construir coisas complexas, é preciso aprender a fazer o simples funcionar.**
